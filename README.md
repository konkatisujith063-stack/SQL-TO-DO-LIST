# SQL-TO-DO-LIST📋
SQL To‑Do List is a beginner‑friendly project showcasing task management with SQL. It covers schema design, CRUD operations, deadlines, and status tracking. Users can add, update, delete, and query tasks, making it a practical foundation for productivity apps.

# SQL To‑Do List 

## 📌 Project Overview
This project demonstrates how SQL can be used to manage everyday productivity tasks and student attendance records.  
It includes two modules:
- **To‑Do List**: Add, update, mark complete, and delete tasks.

---

## 🎯 Objectives
- Practice SQL schema design (tables, relationships, constraints).
- Learn CRUD operations (Create, Read, Update, Delete).
- Use aggregate functions (`COUNT`, `SUM`, `GROUP BY`) for reporting.
- Build a real‑world style database project suitable for portfolios.

---

## HOW TO RUN🚀

- Copy the .sql files into your SQL environment (MySQL, PostgreSQL, or an online compiler).
- Execute the schema creation scripts.
- Insert sample data using the provided queries.
- Run SELECT queries to view reports.

## FUTURE ENHANCEMENTS 🔮
